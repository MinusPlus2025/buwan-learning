# 跟上本地验证版

## 运行

需要 Node.js 22+。当前默认不配置模型，页面仍可查看静态教程并下载练习数据。

```bash
cd clearinfo-agent
npm start
```

打开 `http://127.0.0.1:4173/`。

## 模型配置

截图诊断只会在明确配置视觉模型时启用。复制 `.env.example` 为 `.env`，设置：

```bash
MODEL_PROVIDER=openai
MODEL_BASE_URL=https://your-provider.example/v1
MODEL_NAME=your-vision-model
MODEL_API_KEY=
MODEL_VISION=true
```

服务端保管密钥；不要把真实密钥提交到仓库。发送截图前，用户必须勾选同意处理说明。服务提供方的留存政策未验证，产品不会承诺零留存。

本地默认模型 `qwen2.5:0.5b` 不被视为视觉模型，不能用于截图诊断。模型服务失败、超时、格式不正确或证据不足时，不生成预设答案。
