# 不晚｜想学，就从今天开始

从你的顾虑出发，找到今天能完成的第一步。

## 在线体验

- Demo：https://buwan-learning.app.workbuddy.host/?sharecode=ONOZ6NNVMJ
- GitHub：https://github.com/MinusPlus2025/buwan-learning

请保留 Demo 地址中的 sharecode 参数。后续使用同一项目更新部署，沿用现有链接。

## 本地运行

需要 Node.js 22 或更新版本，无第三方运行依赖。

```bash
npm start
```

默认打开 http://127.0.0.1:4173/。可通过 PORT 环境变量调整端口。服务监听 0.0.0.0，适合单端口 HTTP 部署。

## 可体验的功能

- 十种兴趣选择、顾虑与可用时间配置。
- 可编辑第一步任务；开始、暂停、继续、确认完成。
- 专注模式与计时器。
- 自定义学伴名字、交流风格和对用户的称呼，设置仅保存在浏览器 localStorage。
- 大字模式、浏览器语音输入及语音播报入口，具体支持由浏览器决定。
- 三个学习人物演示情境，均为设计示例。

## AI 与内容接入状态

前端通过 WorkBuddy Cloud SDK 调用云模型，包含访谈和四周学习手册流程。真实模型 completion 和完整手册生成尚未验证成功，不能视为端到端验收通过。

联网搜索尚未配置，/api/search 返回 503。不会将无来源内容作为可核验案例或免费资源。真实数字人尚未接入，仍需提供方凭据与 SDK 集成；页面明确显示未连接状态。

四周手册规划包括起点故事、顾虑回应、可核验案例、免费资源、四周计划、今天十分钟和分享文案。后续方向为持续陪练与复盘、数字人语音互动和可访问性完善。

## 检查

```bash
npm test
node --check server.mjs
node --check public/app.js
```

健康检查接口为 /api/health。当前后端测试覆盖健康状态、来源校验、JSON 类型、未配置搜索、内容来源过滤、四周计划保留及请求体限制。线上接口访问需使用完整分享参数或已建立的访问会话。

## 配置与隐私

可参考 .env.example；不要将密钥提交到仓库。当前模型连接不使用服务端通用代理。输入内容发送给模型前有同意提示；不要输入敏感个人信息。商业模式和学习成效仍为待验证假设。
